# Сравнение направлений

Заполняется после получения кейса. До этого продукт и платформа не выбраны.

Для каждого направления описать: механизм работы, пользу, отличие от текущего способа, MVP, платформу и причину ее выбора, сложность, главный риск и доступность данных.

| Критерий | Вес | Простое надежное | Нестандартное реалистичное | Смелое с сильным демо |
| --- | ---: | --- | --- | --- |
| Ценность | 25 | | | |
| Качество результата | 20 | | | |
| Инновационность | 15 | | | |
| Масштабирование | 20 | | | |
| Презентация и демо | 20 | | | |

Оценки предварительные, с объяснением и уровнем уверенности. Отдельно проверять выполнимость за три часа: высокий балл не компенсирует недоступную обязательную зависимость.

## Проверка нестандартности
- Ближайшие альтернативы и ссылки:
- Какую привычную часть процесса мы меняем и почему:
- Что пользователь сможет сделать лучше и как это показать:
- Почему это преимущество не сводится к добавлению ИИ или оформлению:
- Как возможности веба, десктопа или мобильного устройства помогают сценарию:
- Что пока не подтверждено:

## Рекомендация
- Выбранное направление и причина:
- Основной пользователь:
- Один законченный сценарий:
- Результат и способ измерения:
- Самое рискованное предположение:
- Проверка за 15–20 минут:
- Условие отказа или упрощения:
- Обязательные зависимости и запасные варианты:
- Следующий пользователь/заказчик, условия внедрения и препятствия:
- Что покажем за 60–90 секунд:
