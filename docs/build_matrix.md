## Особенность Windows SDK

В этой среде путь профиля содержит кириллицу. Для Flutter 3.47.5 применён локальный обход в **игнорируемом** SDK: Content-Length анализатора считается по UTF-8 байтам, а инструмент запускается через `flutter_tools.snapshot` с ASCII short-path `FLUTTER_ROOT`. Код приложения не зависит от этого обхода. На другой машине предпочтительно установить Flutter в короткий ASCII-путь; команды проекта остаются стандартными. Native symlink support/Developer Mode не включались, поскольку выбран Web.
