# Игровая дорога карьерного пропуска

Карьерный пропуск открывается на вкладке «100 уровней». `frontend/lib/widgets/career_pass.dart` содержит общий индикатор сезона и горизонтальную дорогу наград. Дизайн сохраняет navy/pink-палитру; сторонние игровые изображения не используются.

- Положение на дороге определяется подтверждёнными XP и `required_total_xp` из серверных наград. Между отметками показывается доля пути до следующего порога, включая путь от стартового уровня 0. Ожидающие проверки XP не заполняют дорогу.
- Верхний индикатор показывает опыт внутри текущего уровня: 0–200 XP. После уровня 100 выводится завершённый пропуск; накопление дополнительных XP не создаёт уровень 101.
- «Ты здесь» обозначает последний открытый уровень. При открытии дороги он попадает в центр видимой области. Кнопки десятков, стрелки, полоса прокрутки и перетаскивание позволяют просматривать остальные награды. «К моему уровню» возвращает к прогрессу, «Забрать награды» — к первому уровню с доступным подарком.
- Карточка показывает состав награды и открывает подробности. CQ и косметика начисляются сервером. Выбор подарка использует существующий сценарий `chooseGift` и доступен только при серверном статусе `available` с идентификатором права на награду. Просмотр карточки ничего не начисляет.
- `credited`/`fulfilled`, `available`, `reserved`, `locked` и `expired` имеют текстовые подписи. Цвет не является единственным различием. Все основные действия доступны с клавиатуры и через семантику Flutter.
- Дорога виртуализирована: создаются видимые карточки, а не полный вертикальный список. Узкие экраны сохраняют горизонтальное пролистывание. Короткие анимации учитывают системное отключение движения.

Проверки: `frontend/test/career_pass_test.dart` проверяет навигацию по дороге, точный идентификатор подарка, запрет получения закрытых/выданных/зарезервированных/просроченных наград, границы 0/199/200/19999/20250 XP и увеличенный текст на 320 px. Общие тесты продолжают проверять переход к ежедневным заданиям.
